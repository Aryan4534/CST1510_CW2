WEEK 8 STARTER PROJECT

1. Open this folder in VS Code.
2. Open Terminal > New Terminal.
3. Install the required libraries:
   python -m pip install requests pandas
4. Run:
   python fetch_data.py
5. The program downloads up to 100 public repositories from the Python
   organisation and saves them to DATA/raw.csv.

This starter uses a public GitHub API endpoint and does not require an API key.
An internet connection is required when running fetch_data.py.
